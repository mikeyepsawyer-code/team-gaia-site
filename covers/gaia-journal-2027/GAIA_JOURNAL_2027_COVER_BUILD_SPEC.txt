SECTION 3 — FRONT COVER (v2 — APPROVED)

STEP 1 — Background
  Load source_ridge_1000065906.jpg, EXIF-correct.
  Scale to canvas width 1725px → resized height becomes 3064px.
  Crop to final canvas height 2625px:
    excess = 3064 - 2625 = 439px
    crop_top = int(439 * 0.15) = 65px (small trim off top)
    crop box: (0, 65, 1725, 65+2625)
  Save as front_bg.jpg, quality=95.

STEP 2 — Bottom darkening overlay (legibility for text)
  Vertical gradient starting at y = int(2625 * 0.60) = 1575
  For each y from 1575 to 2625:
    t = (y - 1575) / (2625 - 1575)
    alpha = int(150 * (t ** 1.3))
    fill (5,5,8,alpha) across full width
  Composite (alpha_composite) onto background.

STEP 3 — Title text block
  Three elements, all left-aligned at x = MARGIN + 20 = 132px,
  stacked bottom-up, anchored above bottom margin.

  GODDESS OF TERRA (anchor — sets the target width for the other two lines):
    Font: Cinzel 600, pt=64
    Render as spaced caps, letter_spacing=10px (manual per-character spacing,
    not font tracking — render each char, advance by char_width + spacing)
    Color: SAGE (150, 185, 140, 255)
    Ink size at this spec: 814 x 48px  ← TARGET_WIDTH = 814px

  Gaia (gold script):
    Font: Parisienne, pt=340 (base render)
    Render ink, then SCALE UP via LANCZOS so width = TARGET_WIDTH (814px)
      scale factor = 814 / raw_ink_width (raw was 635px → scale ≈1.282)
    Apply metallic gold gradient (see SECTION 5 — gradient function)
      GOLD_BASE=(210,160,50), GOLD_HI=(255,235,150)
    Final size: ~813 x 410px

  JOURNAL 2027 (white caps):
    Font: Cinzel 600, pt=78
    Render as spaced caps, letter_spacing=14px
    Color: WHITE (245,245,242,255) — flat, no gradient
    Render ink (raw ≈740px wide), then scale via LANCZOS to TARGET_WIDTH (814px)
      scale factor ≈1.10
    Final size: ~814 x 80px

  LAYOUT (bottom-up):
    bottom_y = 2625 - 112 - 40 = 2473  (baseline anchor)
    sub_y (GODDESS OF TERRA top)  = bottom_y - sub_height(48)        = 2425
    gap2 = 30px
    journal_y (top) = sub_y - gap2 - journal_scaled_height(80)       ≈ 2315
    gap1 = 55px
    gaia_y (top) = journal_y - gap1 - gaia_scaled_height(410)        ≈ 1850

  Paste order: Gaia, then JOURNAL 2027, then GODDESS OF TERRA, each at
  x = 132 (Gaia/Journal nudged +4px for optical alignment: x=136).

STEP 4 — Export
  Flatten to RGB, save as JPEG quality=95 for archive.
  Web/print-ready export: re-save at required DPI/format when uploading to Blurb.

STEP 4 — Bio paragraph (justified, upsized)
  Font: Liberation Serif Regular, pt=44 (upsized from initial pt=36)
  Color: CREAM (225, 218, 200)
  Max width: CANVAS_W - 2*MARGIN - 40 = 1725 - 224 - 40 = 1461px
  Text:

    in the Alberta badlands, where the land itself shapes his work on
    consciousness and divine feminine energy in the sacred everyday.
    Shamanic photography and writing trace a single thread — seeing the
    numinous hiding in plain sight, in rock and river and the turning of
    seasons."
  NOTE: this bio text was reconstructed from a partial mockup screenshot —
  Michael has not explicitly confirmed this exact final wording. Re-confirm
  before treating as permanently locked.

  Wrap algorithm: greedy word-wrap to max_width using textlength() per line.
  Justification: for every line EXCEPT the last line (and except any
  single-word line), distribute extra space evenly between words so the
  line spans exactly max_width:
    natural_width = sum(word_widths) + space_width * (num_gaps)
    extra = max_width - natural_width
    extra_per_gap = extra / num_gaps
    draw each word, advancing by (word_width + space_width + extra_per_gap)
  Last line: render at natural width, horizontally centered (not stretched).
  Block x-origin for justified lines: MARGIN + 20 = 132px
  Line height: 60px
  bio_top = name_y + name_height(197) + 65 ≈ 1802

STEP 5 — Bottom row: barcode (left) / QR (center) / Gaiaridge script (right)
  All three bottom-aligned on a shared row:
    row_bottom = CANVAS_H - MARGIN - 30 = 2625 - 112 - 30 = 2483

  BARCODE (placeholder — NOT a real scannable ISBN, see note below):

SECTION 5 — METALLIC GOLD GRADIENT FUNCTION (shared by all gold elements)

5-stop vertical gradient applied to the alpha mask of rendered text ink.
GOLD_BASE = (210, 160, 50)
GOLD_HI   = (255, 235, 150)
dark_mult = 0.48   (dark = GOLD_BASE * 0.48)
deep_mult = 0.35   (deep = GOLD_BASE * 0.35)

For each row y in the ink image (t = y / height, 0.0 top → 1.0 bottom):
  t < 0.18:  lerp(dark, base, t/0.18)
  t < 0.42:  lerp(base, hi, (t-0.18)/0.24)
  t < 0.54:  flat hi (highlight plateau)
  t < 0.72:  lerp(hi, base, (t-0.54)/0.18)
  else:      lerp(base, deep, (t-0.72)/0.28)

Apply this RGB gradient as a solid color image, then use the original
ink's alpha channel as the mask (paste with itself as mask) so only the
glyph shapes receive the gradient — background stays transparent.

This is the same gradient system used in COVER_PRODUCTION_STANDARD_v3 §3C,
applied here to: front cover "Gaia", back cover "Michael Sawyer" name,
back cover "Gaiaridge" script.
