SECTION 3 — TEXT ELEMENTS (top to bottom)

  1. TITLE "I AM"
     Font: Cinzel 700. target_width = FULL_TEXT_W (1650). top_y = TITLE_TOP_Y
     (169). Tone sampled behind title = midtone -> high_contrast-eligible
     stops but built via gold_finish_for_tone()/scaled_gold_text() default
     (chiseled treatment, STATIC_GOLD_FOIL_STOPS). center_x = CANVAS_W/2.

  2. SUBTITLE, two lines, stacked directly under title (Sep 4 2026 change --
     previously split, with the second line placed near the bottom of the
     cover; Michael asked for both halves reunited under the title)
     Line 1 "the light of being": Parisienne, target_width = 975px
     (measured v7 width ~900px + 75px/0.25in per Michael's explicit
     upsize instruction -- this is a deliberate override of the
     FULL_TEXT_W default subtitle rule, not an oversight).
     top_y = TITLE_TOP_Y + title_ink_height + 55
     Line 2 "crystallizing as selves": same font, same target_width (975px,
     matched to line 1 for a symmetric block rather than same point size).
     top_y = line1_top_y + line1_common_bottom + 60
     Both lines: tone-sampled gold (gold_finish_for_tone), treatment=
     "chiseled" -- NOT harmonized_subtitle_stops(), which was tried first
     and read too pale against this photo's bright cloud cover.

  3. "We are / Me" block (Sep 4 2026 rebuild -- upsized, small-register e's,
     script "are")
     Construction:
       - W: Cinzel 700 @ base pt 320, rendered alone.
       - Small e: Cinzel 700 @ base pt 160 (0.50 x W's pt -- true x-height
         small-caps register, not Cinzel's default lowercase 'e' shape,
         which reads too close to full cap height). Baseline-aligned to W
         via explicit ascent-based baseline math (see render_ink_baseline
         helper -- not in cover_build.py yet, was written ad hoc this
         session; worth promoting to the shared module if this pattern
         recurs).
       - "We" = W + small e, baseline-aligned, -6px kerning gap.
       - "Me" = M + the SAME small e ink reused (not re-rendered).
         M = W.rotate(180) -- NOT a horizontal mirror. A horizontal mirror
         of W returns a W (it's already left-right symmetric in Cinzel).
         180-degree rotation is what produces the M shape. Caught and
         fixed this exact bug during the build -- flag it if rebuilding.
       - "are": Parisienne @ base pt 230, baseline-aligned to We's baseline,
         70px gap after "We".
     Gold treatments:
       - We / Me: apply_chiseled_gold, tone-sampled stops (same
         gold_finish_for_tone as title) -- sampled from the region behind
         this block specifically, not reused from the title's sample.
       - are: apply_chiseled_gold using the SAME stops as the subtitle
         lines above (deliberate -- ties the script accents into one
         visual family across the cover).
     Scaling: "We are" line built at base pt sizes above, then scaled as
     ONE PIECE (post-gold) to WM_TARGET_W = 1450px. The exact same scale
     factor is then applied to the separately-built "Me" piece, so M ends
     up precisely the same absolute size as W -- do not scale Me
     independently to its own target width, or the M/W size relationship
     (M being literally W rotated) breaks.
     Position: line 1 ("We are") top_y = subtitle_block_bottom + 130.
     "Me" top_y = line1_top_y + line1_height + 40.

  4. AUTHOR "Michael Sawyer"
     Font: Cormorant Garamond 400 Italic. target_width = FULL_TEXT_W.
     top_y computed bottom-anchored: CANVAS_H - MARGIN - author_ink_height.
     Tone-sampled gold, chiseled. Per Section 9 standard.
