LAYOUT -- LETTERBOXED (deliberate exception to the usual full-bleed
 portrait crop rule): the landscape painting is kept at its native aspect,
 scaled to full canvas width (1950px), and centered vertically with solid
 black bars above and below rather than cropped to fill the portrait
 canvas. Bar heights are NOT fixed/even by default here -- they're solved
 per Section 0B's balanced-empty-space rule: the picture's vertical
 position is chosen so the actual empty (textless) gap above the picture
 (below the title block) equals the empty gap below the picture (above
 the subtitle block), not simply equal top/bottom bar heights. Recompute
 this whenever title/subtitle/author sizing changes.

TITLE -- "Sapiens" / "Cyberneticus" (two lines, stacked)
 Cinzel 600, pt=190, target_width=FULL_TEXT_W (full width per Section 0B)
 Gap between the two lines: 85px, measured via common_ink_bounds()
 (common bottom of line 1 to common top of line 2) -- NOT raw ink height.
 Gold finish: chosen automatically by first_pass_text() per background
   tone at build time (this book samples as dark bg -> LIGHT GOLD).

SUBTITLE -- "philosophy and morality for an emerging species"
 Liberation Serif Italic, pt=90, target_width=FULL_TEXT_W, all lowercase,
 no ending punctuation (house style). Sits in the bottom text zone.

AUTHOR -- "Michael Sawyer"
 Liberation Serif Italic, pt=130, target_width=FULL_TEXT_W
 Bottom edge at CANVAS_H - MARGIN, bottom text zone.

RULE: (212,158,42), 4px thick, width=55% of FULL_TEXT_W, centered,
 between subtitle and author.

GOLD FINISH SELECTION: built via first_pass_text() (cover_build.py),
 which samples canvas luminance behind each element and applies
 Section 0B's tone->finish mapping automatically -- title, subtitle,
 and author all sampled as dark background here, so all render in
 LIGHT GOLD (PASTEL_GOLD_FOIL_STOPS, chiseled).

PRINT NOTE (Aug 19 2026): pixel dimensions (1950x2850) were always
 mathematically exact for 300dpi at the 6.5"x9.5" bleed canvas, but the
 first export of this master had NO dpi tag embedded in the JPEG --
 pixel-correct but metadata-silent, which some print vendors flag or
 misread. Fixed by re-saving with PIL's dpi=(300,300) parameter
 explicit. CHECK THIS on every future full-res master export -- PIL
 does not embed a dpi tag by default, canvas.save() must pass it
 explicitly or the print file is pixel-correct but tag-silent again.

WEB ASSET SIZE: card exported at quality=60 (not the CARD_QUALITY=74
 default) to hit the <85KB target -- this book's dark, grain-heavy
 painting compresses less efficiently than average at quality 74
 (came out ~103KB there). Check actual output size after export rather
 than trusting the default quality setting produces an on-target file.

NEW TOOL -- ANGLED GOLD FOIL WITH CENTERED HIGHLIGHT
(distinct from Section 3C metallic gradient and Section 3D Kintsugi sine
 function -- this is a new addition to the gold effects toolkit)

 apply_gold_foil_centered(ink_img, angle_deg, deep, base, hi, grain, seed, peak, spread):
  - Angled sweep (default 28 degrees): each pixel projected onto the angle's
    direction vector rather than a pure vertical gradient.
  - Highlight (hi) peaks at peak (0.5 = center of sweep), falls off
    symmetrically to base by spread, then to deep at the far edge.
    Reads as light catching the middle of the letterform -- closer to real
    foil behavior than a one-directional edge-to-edge ramp.
  - Gaussian crinkle grain, seed held constant at 42, default grain=0.05.
  - Needs ~100px+ ink height for the grain to read as texture, not noise.

SCRIM -- tuned to painting palette, not neutral:
 Deep teal-black (9, 26, 24), sampled from this painting's own cool
   register. Top scrim: 0-42% canvas height, max alpha 160, t^2 falloff.
   Bottom scrim: 80%-100% canvas height, max alpha 200, t^2.2 falloff.
