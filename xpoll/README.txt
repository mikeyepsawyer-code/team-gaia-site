xpoll/ — CROSS-POLLINATION OVERFLOW FOLDER
Established August 16, 2026, per Charter v5.8 Section 1F.

WHAT THIS IS: a home for resonant fragments, images, or lines that
surface in a session and seem valuable to the wider library, but don't
yet have a clear book destination, or plausibly serve more than one
book. This replaces Google Drive as the fallback staging location.

WHAT THIS IS NOT: a place for routine material that already has an
obvious home. If a fragment clearly belongs to one book, it goes
straight into that book's manuscript on GitHub — no detour through
here.

CONVENTION: one file per entry, dated and named for its content —
xpoll/YYYY-MM-DD_short-name.txt — status marked RED until Michael
approves a destination and it migrates into a manuscript (at which
point this file can be deleted).

PRE-EXISTING MATERIAL: two entries predating this folder live in
charter/ instead — charter/XPOLL_2026-07-28_heart-verb-nature.txt and
charter/XPOLL_2026-08-01_four-words-icon.txt. These may be migrated
here later for consistency; no urgency.
