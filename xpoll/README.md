# XPOLL — Cross-Pollination Staging

Established Aug 20, 2026, replacing scattered Drive staging notes.

## Purpose

Home for material whose book placement is genuinely uncertain: fits
more than one book, or no manuscript exists yet for the book it might
belong to. Per the XPOLL protocol (charter Section 1G), direct
insertion into the relevant manuscript is the default whenever
placement IS clear — this folder is only for the cases where it isn't.

## Rules

- One file per idea/fragment, not one growing catch-all file.
- Filename pattern: `v0.1_XPOLL_<SHORT_TOPIC>.txt`
- Every file states: source (verbatim from Michael / Claude draft),
  date, and a list of candidate book placements.
- Once a manuscript exists and placement is decided, migrate the
  material into that manuscript (dated, marked candidate per normal
  convention) and DELETE the file from this folder. Nothing should
  sit here indefinitely — this is a waiting room, not storage.
- Session-start check: whenever starting work on any book, also
  glance at this folder for anything that might now have found its
  home.

## Why GitHub instead of Drive

Simplifies Drive to source photos and large binaries only. Everything
text-based and placement-uncertain lives here instead, versioned,
searchable, and in the same place as everything else it might
eventually join.
